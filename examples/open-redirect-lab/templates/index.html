Open Redirect Training Lab

A deliberately vulnerable local application for security testing practice.

1. Vulnerable endpoint

GET /redirect?url=DESTINATION

The application takes the url parameter and puts it directly into the HTTP Location response header. There is no destination validation.

2. Safer comparison endpoint

GET /safe-redirect?url=DESTINATION

This comparison route allows same-site paths such as / and rejects absolute external URLs. It is included so you can compare the HTTP responses.

3. Quick checks

Health check: /healthz

Try the vulnerable route with an external destination and inspect the response. A typical result is HTTP/1.1 302 FOUND with a Location: https://example.org header.

Keep this lab on localhost. Do not expose the intentionally vulnerable service to a public network.
